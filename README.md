# Paradise Nursery Shopping Application

## Project Name
Paradise Nursery

## Description
Paradise Nursery is a React and Redux shopping cart application for an online plant nursery. Customers can browse houseplants by category, view plant information, add plants to a shopping cart, change quantities, remove products, and see updated item and cart totals.

## Main Features
- Landing page with Paradise Nursery branding and Get Started button.
- About Us company information.
- Three plant categories with six unique houseplants in each category.
- Plant thumbnail, name, description, and price.
- Add to Cart functionality with the button disabled after an item is added.
- Dynamic cart item count in the navigation bar.
- Redux cart state using addItem, removeItem, and updateQuantity reducers.
- Shopping cart with quantity controls, item totals, cart total, delete buttons, Checkout, and Continue Shopping.
