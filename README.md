# Paradise Nursery Shopping Application

## Project Name
Paradise Nursery

## Description
Paradise Nursery is a dynamic online plant shop created as a final project. Users can browse plants, view plant details, add products to a shopping cart, change quantities, remove products, and see the cart total update automatically.

## Features
- Responsive navigation bar
- Plant product catalog
- Plant names, categories, descriptions, prices, and visual icons
- Add-to-cart functionality
- Dynamic cart item count
- Increase and decrease item quantities
- Remove items from the cart
- Automatic subtotal and total calculation
- Cart persistence using browser localStorage
- Responsive layout for desktop and mobile screens

## Technologies
- HTML5
- CSS3
- JavaScript
- Browser localStorage
