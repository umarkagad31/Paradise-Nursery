# Paradise Nursery Shopping Application

## Project Name
Paradise Nursery

## Description
A React and Redux shopping cart application for an online plant shop. Users can browse houseplants by category, add plants to a cart, change quantities, remove items, and view total costs.

## Required Files
- `src/components/AboutUs.jsx`
- `src/App.css`
- `src/App.jsx`
- `src/store/CartSlice.jsx`
- `src/components/ProductList.jsx`
- `src/components/CartItem.jsx`

## Features
- Landing page with company name and Get Started button
- Company information
- Three categories with six plants per category
- Plant thumbnails, names, and prices
- Add to Cart buttons disabled after adding
- Dynamic cart count
- Redux Toolkit cart
- Quantity controls and delete buttons
- Cart total calculation
- Checkout Coming Soon message
- Continue Shopping link

## Run
`npm install`
`npm run dev`
